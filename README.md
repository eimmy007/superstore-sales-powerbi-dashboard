# Superstore Sales Performance Dashboard

## Project Overview
This project shows complete data cleaning and interactive dashboard creation using Power Query and Power BI.

**Dataset:** Sample Superstore (500 rows)  
**Tools Used:** Power Query, Power BI, DAX

## Business Problem
A retail company needed clean sales data and an interactive dashboard to track sales performance, profit, and customer segments.

## What I Did
- Cleaned the data using Power Query (fixed data types, cleaned text columns, handled missing values)
- Created DAX measures for key KPIs
- Built an interactive dashboard with KPI cards, charts, and slicers

## Dashboard Features
- KPI Cards: Total Sales, Total Profit, Profit Margin %, Number of Orders, Average Discount
- Sales by Category
- Sales by Region
- Sales by Segment
- Interactive Slicers (Region, Category, Segment)
